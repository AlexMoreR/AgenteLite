## Qué no existe hoy
- `contactos_compartidos`: las tarjetas de contacto (vCard) que llegan por WAHA se ven en el chat como texto ("👤 Contacto: nombre · teléfono"), no como una tarjeta con botón para guardar el contacto.
- `ubicacion_en_tiempo_real`: si cada actualización de una ubicación en tiempo real llega con otro número de mensaje, puede salir una burbuja de ubicación por cada una; no se juntan en una sola.
