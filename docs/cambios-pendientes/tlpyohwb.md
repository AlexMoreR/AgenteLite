## Advertencias de operación
- `reversion_falsa`: antes de deshacer una subida que "no arrancó", el Coordinador espera al menos 15 min desde la subida (`subida.pisoVersionMinutos`) y lee por ssh las últimas 300 líneas de `/var/log/crm-actualizar.log` (`subida.logActualizar`, solo lectura); si el log no dice `listo: version <sha>` con el commit subido o uno posterior, la reversión es "falsa": no cuenta para el tope de 3 subidas deshechas y en la vuelta siguiente se sube el mismo commit. Si ese log se mueve o cambia de formato, las reversiones de verdad se ven como falsas y se reintentan.
