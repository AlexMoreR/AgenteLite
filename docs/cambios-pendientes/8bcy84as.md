## Módulos
- `chats`: el buscador de la bandeja busca en todos los estados (abiertos, pendientes, cerrados, archivados y pospuestos), aunque la pestaña de estado diga otra cosa, y encuentra el número escrito con o sin el 57. El enlace directo `/cliente/chats?conversacion=<id>` abre ese chat (de WhatsApp normal o de la API oficial) con el estado en "Todas" para que se vea aunque esté cerrado; pasa por la misma regla de acceso que `?chatKey=` (línea visible, asesora dueña del chat, modo monitoreo). Si el id no existe o la persona no puede verlo, se abre la bandeja normal sin error.
