## Advertencias de operación
- `tarjetas_del_coordinador_en_features`: toda tarjeta que crea el Coordinador solo (causa externa como "Vigilancia: … revirtió una subida", limpieza de main y partes de una tarjeta partida) cuelga de Features (T-736, por su id fijo) y nunca queda suelta en la vista principal; las partes de una tarjeta que ya estaba dentro de Features siguen colgando de ella o de su padre. Cada arranque del Coordinador cuelga de Features, sin cambiarles el estado, las que él creó y quedaron sin padre en ese tablero (nota "movida dentro de Features" en el historial). Como quedan dentro de Features, les aplica la regla Features: el Coordinador las toma y las sube solas.
