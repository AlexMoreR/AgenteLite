## Qué no existe hoy
- `candado_no_reasignar_boton`: el candado "No reasignar" ya tiene su acción del servidor (`fijarCandadoNoReasignarAction`), pero todavía no hay botón en el chat; solo vale para WhatsApp normal, no para la API oficial.

## Advertencias de operación
- `candado_no_reasignar`: lo prende solo la asesora asignada; lo apaga ella o un jefe (dueña, admin o supervisora), y cada cambio deja una nota gris en el chat ("prendió el candado (no reasignar)", "apagó el candado", "quitó el candado"). No bloquea el pase manual: si el chat cambia de asesora, el candado se borra. También se borra al pasar el contacto a Ganado o Perdido desde el CRM.
